# Storytime-канал: аналитика и план производства

Файл-контекст для Claude Code. Прочитай целиком перед созданием субагентов и роликов.

## 1. Что за проект

- Аккаунт с ИИ-анимированными storytime-роликами на русском (истории с Reddit и не только).
- Формат: серия из 3–4 частей, каждая заканчивается клиффхэнгером.
- Площадки: TikTok (основная, есть данные), YouTube Shorts, Instagram Reels.
- Озвучка: TTS через Speko, текущий голос оставить. После каждой задачи сообщать остаток баланса Speko.

## 2. Данные TikTok за 2–8 ноября 2026

Источник: скриншоты аналитики аккаунта. Аккаунт новый, до 2 ноября данных нет.

| Метрика | Значение | Доля от просмотров |
|---|---|---|
| Просмотры публикаций | 7 300 | — |
| Уникальные зрители | 4 700 (все новые) | — |
| Просмотров на зрителя | ~1,55 | — |
| Лайки | 502 | ~6,9% |
| Комментарии | 1 | ~0,01% |
| Репосты | 6 | ~0,08% |
| Просмотры профиля | 194 | ~2,7% |
| Доход | $0 | — |

Источники трафика: «Для вас» 93,2%, профиль 5,7%, поиск 1,1%, подписки 0%, звук 0%.

Поисковые запросы (по 1,2%): «шифр 4», «Story Time», «3 часть про неадекватного таксиста», «Касета 80», «Истории».

Динамика по дням: пик ~1,9К просмотров 4 ноября, дальше ровное падение до ~750 к 8 ноября.

Активность зрителей: максимум около 00:00–01:00 по Чите (UTC+9), это ~18:00–19:00 по Москве. График за 9 ноября неполный, перепроверить на вкладке «Дни».

### Чего в данных НЕТ (и это главное)

- Среднее время просмотра, процент досмотревших и график удержания по каждому ролику.
- Разбивка метрик по отдельным роликам.

Без этого вывод про удержание остаётся гипотезой. Первым делом запросить у владельца скрины «Контент → ролик» по каждой части.

## 3. Выводы

**Работает**
- Алгоритм раздаёт: 93% из рекомендаций, ограничений на аккаунте нет.
- История нравится: ~7% лайков, это выше среднего.
- Серийность работает: 1,55 просмотра на зрителя, продолжение ищут через поиск.

**Не работает**
- Комментариев фактически ноль. Это главный тормоз второй волны показов.
- Репостов почти нет.
- Вторая волна рекомендаций не пришла (график только вниз). Вероятная причина: удержание. Не подтверждено.
- Следующую часть трудно найти: зрители ищут её вручную.

**Про деньги**
- Выплаты TikTok за просмотры в РФ недоступны, AdSense для новых каналов из РФ не подключают.
- Shorts платят порядка $0,03–0,10 за 1000 просмотров, длинные видео порядка $3–12.
- Реальный путь: шортсы как воронка в длинные склейки (8+ минут), Telegram, партнёрки, прямая реклама.

## 4. Правила производства

### Обязательные (требования владельца)

- Темп быстрый, «ADHD-стиль»: ускоренный голос, частые склейки. Прошлые ролики зритель назвал затянутыми.
- Подача живая: энергичный голос, яркая картинка.
- Часть НЕ начинается с пересказа прошлой. У каждой части свой хук.
- Описания, обложки и клиффхэнгеры не спойлерят следующие части.
- Перед сборкой каждая серия проверяется на нестыковки между частями.
- Обложка для каждой части.
- Толпа и прохожие двигаются хаотично и живо, не строем. Персонажи не проходят сквозь друг друга.
- Перед новой серией предлагать несколько историй на выбор.
- Для нового визуального стиля сначала короткий тизер, потом полная серия.

### Новые (из аналитики)

1. Хук в первые 2 секунды: конфликт или ставка в первой фразе.
2. Каждая часть заканчивается вопросом к зрителю, который делит аудиторию («кто прав?»). Цель: комментарии.
3. В названии и на обложке всегда «Часть N» и одно и то же имя серии, чтобы находилось поиском.
4. Смена кадра каждые 1,5–3 секунды, крупные динамичные субтитры.
5. Тест длины: 35–50 секунд против текущих 1:15–1:30. Решение принимать по удержанию.
6. Публикация за 1–2 часа до пика, то есть около 16:00–17:00 МСК. Части серии выходят подряд, без разрыва в несколько дней.
7. Без вотермарок других площадок при кросспостинге.
8. Один визуальный стиль минимум на 10–15 роликов подряд.
9. После серии собирать длинную склейку всех частей для YouTube.

### Риски

- YouTube с июля 2026 не монетизирует шаблонный однотипный ИИ-контент. Нужен заметный авторский вклад: отбор и переработка историй, свой стиль, свой монтаж.
- Истории с Reddit переписывать своими словами, не копировать текст.
- Отмечать ИИ-контент при загрузке там, где площадка этого требует.

## 5. Субагенты для Claude Code

Конвейер последовательный. Не плодить агентов сверх этого списка: больше агентов означает больше рассинхрона стиля. Каждый файл кладётся в `.claude/agents/`.

### story-scout.md

```markdown
---
name: story-scout
description: Подбирает и предлагает истории для новой серии. Вызывать в начале работы над серией.
tools: WebSearch, WebFetch, Read, Write
---
Найди 5 историй с ярким бытовым конфликтом. Для каждой дай: суть в 2 предложениях,
хук первой фразы, точки клиффхэнгеров для 3-4 частей, спорный вопрос для комментариев.
Не копируй исходный текст, пересказывай. Ничего не выбирай сам: выбор делает владелец.
```

### scriptwriter.md

```markdown
---
name: scriptwriter
description: Пишет сценарий серии по выбранной истории. Вызывать после выбора истории владельцем.
tools: Read, Write, Edit
---
Напиши сценарий серии из 3-4 частей на русском по правилам раздела 4 файла
storytime-analytics.md. Каждая часть: хук в первой фразе, без пересказа прошлой части,
клиффхэнгер, финальный вопрос к зрителю. Темп быстрый, фразы короткие.
К каждой части приложи раскадровку: кадр, длительность 1,5-3 с, текст субтитра.
Отдельно дай название, описание и текст обложки без спойлеров.
```

### continuity-checker.md

```markdown
---
name: continuity-checker
description: Независимо проверяет сценарий серии до производства. Вызывать после scriptwriter, всегда.
tools: Read
---
Ты видишь только готовый сценарий, без истории его создания. Проверь:
1) спойлеры в названиях, описаниях, обложках и клиффхэнгерах;
2) нестыковки между частями (имена, факты, хронология);
3) силу хука: зацепит ли первая фраза за 2 секунды;
4) провисающие места, где зритель уйдёт;
5) есть ли в конце каждой части вопрос, на который хочется ответить.
Верни список замечаний с номером части и строкой. Сам текст не правь.
```

### producer.md

```markdown
---
name: producer
description: Собирает ролик: озвучка, визуал, монтаж, субтитры, обложка. Вызывать после прохождения проверки.
tools: Read, Write, Edit, Bash
---
Собери части по утверждённому сценарию и раскадровке. Голос Speko прежний, темп ускоренный.
Стиль визуала единый для всей серии. Толпа двигается хаотично, персонажи не пересекаются.
Вертикаль 9:16, крупные субтитры, обложка для каждой части с надписью «Часть N».
После сборки сам просмотри результат по кадрам и сообщи остаток баланса Speko.
```

### Порядок работы

1. `story-scout` → владелец выбирает историю.
2. `scriptwriter` → сценарий.
3. `continuity-checker` → замечания → `scriptwriter` правит. Повторять, пока замечаний нет.
4. `producer` → тизер (если стиль новый) → полная серия.
5. Через 3–5 дней после публикации владелец даёт скрины удержания, выводы дописываются в этот файл.

Параллелить можно только два места: генерацию нескольких вариантов хука и сборку разных частей после утверждения сценария.

## 6. Что запросить у владельца в первую очередь

- Скрины удержания по каждому опубликованному ролику.
- Какой визуальный стиль был у серии про таксиста (она дала текущие цифры).
- Сами видеофайлы опубликованных частей для разбора по секундам.
