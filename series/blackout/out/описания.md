# Блэкаут — тексты для публикации

Серия-гайд из 7 частей. Выкладывать по 2–3 части в день, по порядку.
Источники: ready.gov и CDC (США) — в описании части 4 стоит их упомянуть.
В конце каждой части просьба сохранить серию: для гайдов сохранения — главный сигнал алгоритму.
На TikTok отметить ИИ-контент (ИИ-голос).
